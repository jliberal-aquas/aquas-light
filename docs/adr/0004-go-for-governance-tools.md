# Las herramientas del gobierno se escriben en Go

El humano eligió Go el 18-nov por encima de Python. Gana un binario rápido y tipos estrictos para validar esquemas; a cambio, cada máquina necesita el compilador de Go para instalar el paquete.

## Considered Options

- Python 3 sin dependencias: casi siempre instalado, tipos débiles.
- Bash con `jq`: frágil de probar.
