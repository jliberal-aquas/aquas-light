# JSON para la máquina, Markdown para el humano

Todo lo que lee una herramienta o un agente va en JSON con esquema: backlog, memoria, solicitudes, telemetría, roles y sellos. Todo lo que lee el humano va en Markdown: wiki, ADR y reglas en prosa. Así las validaciones son deterministas; por eso `canon/roles.json` reemplaza a `canon/roles.md` como fuente.
